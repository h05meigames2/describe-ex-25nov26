# Describe Your Ex in One Word

My one-word verdict on an ex: **deprecated**. In software, a deprecated feature still exists — but it is no longer supported, no longer maintained, and the release notes warn everyone to stop using it. That is exactly what an ex is: technically still in the world, officially out of support, and every future version ships without them.
